日本語化プロジェクト

Wasteland 2 / Wasteland 2: Director's Cut

ウェイストランド2 日本語化パッチ

Steam 版の「Wasteland 2」（2014年の最初の版）と「Wasteland 2: Director's Cut」を日本語で遊べるようにする、非公式のファンメイド日本語化パッチです。 人物との会話とキーワード、戦いの知らせ、キャラクター作成、技能・特技・クセ、品物の名前と説明、業務日誌、メニューとオプション、読み込み画面のヒントまで、ゲームの中の文章を日本語にしています。 ゲームのフォルダにファイルをひとつ置くだけで日本語になり、消せば英語に戻ります。

ダウンロード（GitHub）

どんなゲーム？

ウェイストランド2は、1988年の「ウェイストランド」の続編として、inXile entertainment が2014年に発表した、核戦争後のアメリカを舞台にしたロールプレイングゲームです。 前作から15年。砂漠のレンジャーの古参、キャプテン・エースが何者かに殺されました。 新兵のレンジャー4人となってその死を調べるうちに、アリゾナの荒野、そしてロサンゼルスへと、人類の行く末にかかわる事件をたどっていきます。

ターン制の戦闘と、銃や交渉、錠前破りやトースター修理といった技能の使い分けで道を開くのがこのゲームの持ち味です。 会話では、文の中の色のついたキーワードをクリックしたり、言葉を打ち込んだりして話を聞き出します。 2015年の Director's Cut では、クセや特技、完全な音声、新しい会話などが加わりました。このパッチは両方の版に対応しています。

入れ方

Wasteland2_JP.zip の中に、版ごとのフォルダがあります。持っている版のフォルダの version.dll を使ってください。

Steam での名前使うファイル置き場所
Wasteland 2: Director's CutDirectorsCut\version.dllゲームのフォルダの中の Build フォルダ（WL2.exe があるフォルダ）
Wasteland 2（最初の版）Classic\version.dllゲームのフォルダの中の Build フォルダ（WL2.exe があるフォルダ）
  1. Steam のライブラリでゲームを右クリックし、「管理」→「ローカルファイルを閲覧」でゲームのフォルダを開きます。
  2. その中の Build フォルダに、版に合った version.dll を置きます。
  3. いつもどおり Steam から起動します。

ゲームのファイルは書き換えません。起動したとき、日本語の文章の表を %LOCALAPPDATA%\WL2_JP に書き出して、ゲームにはそちらを読ませます。

外し方

  • Build フォルダから version.dll を消します。
  • 書き出した表も消したいときは、%LOCALAPPDATA%\WL2_JP のフォルダを消します。

セーブデータは英語版と共通です。

遊ぶときの注意

  • Director's Cut は、オプションの「言語」を English のままにしてください。ほかの言語にすると日本語になりません。
  • 会話のキーワードは、ボタンや文の中の色のついた言葉をクリックすれば使えます。言葉を打ち込んで尋ねるときは、英語版と同じ英語で打ち込みます（例: 任務なら duty）。日本語は打ち込めません。
  • キャラクターの名前は英字で入力します。最初からいる仲間や町の人の名前はカタカナにしています。
  • キー割り当ての画面のキーの名前（Space、PageUp など）は英語のままです。
  • ゲームの中の絵になっている文字（タイトルのロゴ、冒頭の映像のクレジットなど）は英語のままです。冒頭の映像の語りには字幕はありません。
  • 文字は Windows に入っている日本語のフォントで表示されます。狭い欄では行の間が詰まって見えるところがあります。
  • ゲームが新しい版になって中身が変わると、一部が英語に戻ることがあります。
